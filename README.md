# ActiveClear MVP

One profile. Every credential. Every sport.

## Included
- Supabase email/password authentication
- Profile home dashboard
- Basic personal record
- Emergency contact information
- Medical information and optional insurance
- Credential wallet with private file uploads
- Fraud/authenticity attestation on credential uploads
- Organization connections
- Requirement-to-credential matching structure

## Supabase
Project: `ActiveClear`

Copy `.env.local.example` to `.env.local` before running locally.

## Run
```bash
npm install
npm run dev
```
